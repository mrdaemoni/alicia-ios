# Tab presence — evidence

`five-tabs.png` — the five product surfaces side by side (Us · Dialogue ·
Alicia · Studio · Knowledge), captured with `--tab <name>` on iPhone 17,
after point-count opacity normalisation. Each carries a visibly distinct
family and none competes with its text.

`rejected-figure-at-1x.png` — the first attempt, kept because it shows the
mistake plainly: `AliciaPresence` dropped in at 1:1 is a *figure*, and it
clustered mid-screen as a smudge across the greeting. A tab background has to
be a *field*, which is why the shipped version oversizes the body to push its
dense core off-canvas.

Captured from `opus/tab-presence`. Device verification on Pandaiux is
Hector's call, per AGENTS.md §4.
